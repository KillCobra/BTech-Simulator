# Bunk Master — Roadmap

## Done (v1)
- [x] Voxel diorama campus, first-person students in uniform, host/join lobby
- [x] Teachers (write/watch/patrol/attendance), gate guard, peon, suspicion, chase, lockers, detention, win at chai stall
- [x] Phase 1: interaction system, inventory (Hall Pass, Samosa, Medical Note, Canteen Key), phone, paper-ball
      distraction, pings, proxy attendance, friend boost, fire alarm
- [x] Phase 2: 8 side quests (3 per player), round timer (5/8/12 min), final bell, results screen, back to lobby
- [x] Phase 3: staff room + library + washrooms, CCTV (calls staff), prefect + vice-principal patrols,
      canteen uncle, back door, mural, service gate
- [x] Phase 4: NPC students (seated + walking, crowd cover), seated poses, guard's chai glass,
      procedural audio (bell, footsteps, blip voices, whistle, siren, chase/calm music, stingers, birds)
- [x] Phase 5: lobby character creator with 3D preview, pause menu, settings (mouse, FOV, volumes, graphics, fullscreen)
- [x] Phase 6: join a round in progress, rejoin keeps progress
- [x] Phase 7: Windows build `export/BunkMaster.exe`

- [x] Phase 8: four big maps (Grand Campus, Whispering Pines, Lagoon Island, Downtown Campus) + random pick,
      water you can fall into, map guards/patrols/cameras, new university name, diverse staff names
- [x] Phase 9: First Day starter map (original school) + a big, different multi-storey university building on
      every other map (quadrangle, timber lodges, marine institute, twin towers), built from a wing/room kit
